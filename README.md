## 1. Overview

**KXM Clothing** is an editorial e-commerce platform crafted for an avant-garde streetwear and contemporary apparel label. Drawing inspiration from modern brutalist editorial publications, high-fashion runway archives, and Tokyo street culture, the digital experience presents clothing not just as retail SKUs, but as limited numbered artistic volumes.

The experience prioritizes tactile visual pacing, oversized typography, horizontal lookbook scrolling, seamless product exploration, and dynamic client-side bag interactions.

---

## 2. Key Features

- **Numbered Collection Drops:** Structured seasonal volumes with drop counters, limited batch quantity indicators, and garment fabric breakdowns (GSM, weave, origin).
- **Horizontal Editorial Lookbook (`lookbook.html`):** Smooth horizontal panning gallery allowing shoppers to explore seasonal editorial campaign imagery and lookbook stylings.
- **Interactive Shop Grid (`shop.html`):** Category filtering across outerwear, heavyweight tees, relaxed trousers, accessories, and archive pieces.
- **Dynamic Product Pages (`product.html`):** Multi-angle product imagery, size selector with measurements, fit recommendation guide, and immediate cart drawer trigger.
- **Persistent Slide-Out Bag:** Real-time shopping bag with item quantity controls, subtotal tallying, persistent local storage, and streamlined checkout redirection.
- **Brand Narrative & Policy Pages:** Minimalist brand manifestos, transparent shipping timelines, sustainable fabric commitments, and return protocols.
- **Clean Responsive Engineering:** Mobile-first fluid typography and touch gesture-optimized horizontal scrollers.

## 5. Getting Started

### Local Setup
The codebase is structured as a static, buildless web application.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/diu-ctrl/KXM-Clothing.git
   cd KXM-Clothing
   ```

2. **Serve locally:**
   Run any static web server in the project root:
   ```bash
   # Using npx serve:
   npx serve .

   # Or using Python 3:
   python -m http.server 3000
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.
